# CaseMindGroup - BlogApp

Repositório unificado (Monorepo) contendo o Backend e Frontend da aplicação de Blog desenvolvida para o processo seletivo Mind Group.

---

## 📁 Estrutura do Projeto

```
CaseMindGroup/
├── backend/       # API RESTful (Node.js / TypeScript / Express / PostgreSQL)
├── frontend/      # Aplicação Web (React / TypeScript)
└── README.md
```

---

## 🚀 Como Executar

### 1. Backend
Consulte os detalhes de configuração e banco de dados em [`backend/README.md`](./backend/README.md).

```bash
cd backend
npm install
npm run dev
```

### 2. Frontend
Consulte os detalhes de execução da interface em [`frontend/README.md`](./frontend/README.md).

```bash
cd frontend
npm install
npm start
```
